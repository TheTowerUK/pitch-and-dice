# Pitch & Dice — Sound Assets

Place these MP3 files in this folder to enable sound effects.
All sounds are optional — missing files are silently skipped.

## Required Files

| File | Sound | Suggested Source |
|------|-------|-----------------|
| roll.mp3 | Dice rolling | freesound.org: "dice roll" |
| bat_crack.mp3 | Bat hitting ball | freesound.org: "cricket bat" |
| crowd_six.mp3 | Crowd cheering a six | freesound.org: "crowd cheer" |
| crowd_four.mp3 | Crowd applauding a four | freesound.org: "crowd applause" |
| wicket.mp3 | Stumps rattling | freesound.org: "cricket stumps" |
| crowd_groan.mp3 | Crowd groan on wicket | freesound.org: "crowd groan" |
| milestone.mp3 | Fanfare for 50/100 | freesound.org: "fanfare" |
| drs.mp3 | Electronic beep for DRS | freesound.org: "electronic beep" |

## Free Sound Sources
- https://freesound.org (requires free account)
- https://www.zapsplat.com (requires free account)
- https://mixkit.co/free-sound-effects/

## Format Requirements
- Format: MP3
- Duration: 0.5s–3s recommended
- Keep file sizes small (under 200KB each)
