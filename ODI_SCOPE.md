# ODI scope decision

## Summary

ODI is implemented as a **50-over format** to extend match length and atmosphere.

It is **not** intended to replicate full real-world ODI rules or pacing at this stage.

The current implementation **reuses existing engine behaviour** with **minimal format-specific tuning**.

Further ODI-specific enhancements (AI phases, pressure scaling, event tuning) will be considered **post-release**, based on user feedback and engagement.

**Priority:** No formats longer than ODI (e.g. Test refinement) will be prioritised until ODI usage and feedback justify that investment.

*This note records product/engineering intent; implementation details may evolve.*
