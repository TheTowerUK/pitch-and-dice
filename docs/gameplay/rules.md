# Rules

## Core Cricket Rules (Game Scope)

- Match progresses by legal deliveries
- Wickets reduce available batting resources
- Innings ends by wickets, balls, or chase completion
- Winning condition determined by target and innings state

## In-Game Principles

- Deterministic scoring updates
- Consistent wicket confirmation flow
- Clear transitions between innings and result states
