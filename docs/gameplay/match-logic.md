# Match Logic

## Flow

- Select teams and match setup
- Resolve each ball outcome
- Update score, wickets, strike, and phase
- Handle over completion and innings transitions
- Resolve final match result

## Key Logic Areas

- Ball resolution pipeline
- Wicket confirmation and DRS behavior
- Pressure and required rate context
- End-of-innings and match-end conditions
