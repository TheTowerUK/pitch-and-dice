# V1 Scope

## Product Goals

- Deliver a stable and complete match experience
- Provide polished core gameplay and commentary
- Ensure release quality for broader testing

## In Scope

- Core match flow from toss to result
- Batting, bowling, wicket, over, innings transitions
- Commentary and audio playback integration
- Scoreboard and key in-match UI components
- Team selection and fictional team support

## Out of Scope (V1)

- Multiplayer
- Live services / online sync
- Advanced analytics dashboards
- Cosmetic customization marketplace

## Exit Criteria

- Critical bugs resolved
- Regression checklist fully passed
- Real-device validation completed
