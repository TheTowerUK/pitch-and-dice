# 🧪 Testing Checklist

> Copy your GitHub checklist here (same content).

## Smoke

- App launches cleanly
- Match can start and complete
- No crashes during core flow

## Core Gameplay

- Toss to innings transitions work
- Wickets, runs, overs, and target logic are correct
- Match result resolution is accurate

## Audio & Commentary

- Lead/analyst/general commentary sequencing works
- Ambient audio behavior is correct across phases
- No invalid commentary lines for edge cases

## UI

- Scoreboard reflects current state
- Batter names resolve from team data
- Modals and overlays render correctly
