# 📱 TestFlight Checklist

> Copy TestFlight checklist here.

## Pre-Upload

- Version/build numbers incremented
- Release notes drafted
- Required env/config validated

## Upload & Processing

- Build uploaded successfully
- Processing completed without warnings
- Test groups configured

## Validation

- Install on test devices succeeds
- Critical gameplay scenarios pass
- Audio/commentary and UI checks pass

## Sign-off

- QA sign-off captured
- Known issues documented
- Go/No-Go decision recorded
